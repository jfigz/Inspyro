# Structural Report Demo

This workspace is a small, deterministic example for trying Inspyro's notebook-first report workflow.

## Files

- `inputs/beam_case.json`: structural input data.
- `beam_design.py`: calculation helpers.
- `beam_report.ipynb`: notebook entry point for the report.

## Flow

1. Open this folder as an Inspyro workspace.
2. Open `beam_report.ipynb`.
3. Run all cells.
4. Review the calculated demand/capacity ratio and generated report text.
