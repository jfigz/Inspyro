# Changelog de Módulos

> **Última actualización:** 2026-02-24
> **Formato:** `docs/changelog/<id>-<slug>.md`

---

## Objetivo

Centralizar historial de cambios extensos para mantener los módulos técnicos limpios y navegables para IA.

## Convención de entradas

### Encabezado
- `## YYYY-MM-DD - Título corto`

### Cuerpo mínimo
1. Contexto.
2. Cambios técnicos.
3. Riesgos/impacto.
4. Archivos afectados.

## Regla

Si un módulo recibe cambios significativos, actualizar su changelog correspondiente y dejar en el módulo solo un resumen con enlace.
